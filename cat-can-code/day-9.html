Flashcards - AWS Core Concepts

Service Meaning Mental model
CloudFront CDN that speeds up global delivery. Food delivery hubs worldwide.
S3 Scalable file storage for images, videos, and static assets. Storage warehouse.
EC2 Virtual server that runs backend applications. Your kitchen space.
Lambda Serverless compute that runs code on demand. On-demand mini chef.
API Gateway Entry point for APIs, routing, and auth. Restaurant front door.
RDS Managed SQL database. Ingredient database.
ElastiCache Managed Redis for faster reads. Pre-cooked meals.
VPC Private network that isolates your system. Restaurant land.
IAM Users, roles, and permissions. Security guard.

Real Flow

Here is what happens when Cat opens the app.

1. Request hits CloudFront
2. Static content comes from S3
3. Dynamic request goes to BFF (Next.js / API Gateway)
4. BFF calls NestJS on EC2
5. Backend checks Redis in ElastiCache
6. If needed, backend fetches from RDS
7. Response goes back to the user

Key Architecture Insight

Delivery -> CloudFront
Storage -> S3
Compute -> EC2 / Lambda
Cache -> Redis
Database -> RDS
Security -> IAM
Each AWS service solves one problem extremely well.

Two Ways to Build

Option 1: Server-based

EC2 -> run everything
  • More control.
  • More DevOps responsibility.

Option 2: Serverless

Lambda + API Gateway
  • Less management.
  • Easier scaling.

Most real systems end up hybrid, because different parts want different tradeoffs.

Security Thinking

  • IAM controls who can access what.
  • VPC isolates the network.
  • BFF validates requests before they spread inward.
  • Backend enforces business rules.
Security is layered, not single-point.

What You Understand Now

  • You can map frontend, backend, and cloud together.
  • You understand where each service fits.
  • You are thinking in systems, not tools.
  • You can start designing scalable architecture.

Final Cat Story

Cat opens a global restaurant.

  • CloudFront delivers food worldwide.
  • S3 stores menus and images.
  • The waiter takes the order.
  • The manager processes it.
  • The chef cooks it.
  • Redis serves the fast dishes.
  • RDS stores the ingredients.
A great restaurant is not one kitchen. It is a system of coordinated services.

Final Day 9 Takeaway

  • AWS is a system of specialized services.
  • Architecture is how you connect them.
  • Scaling comes from better composition, not just bigger machines.
Cloud architecture means connecting the right services instead of building everything yourself.
